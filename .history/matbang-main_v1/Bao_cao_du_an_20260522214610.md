# Báo cáo dự án SpaceRent

## 1. Mục tiêu dự án

SpaceRent là nền tảng tìm kiếm và gợi ý mặt bằng cho thuê, hướng tới hỗ trợ người dùng:
- Tìm kiếm nhanh mặt bằng theo vị trí, giá, diện tích và loại hình kinh doanh.
- So sánh nhiều phương án mặt bằng cùng lúc.
- Lưu lịch sử tìm kiếm và danh sách yêu thích.
- Xem chi tiết mặt bằng, bản đồ và chỉ đường.
- Hỗ trợ tìm kiếm thông minh bằng chatbot AI.
- Quản trị dữ liệu và thống kê qua dashboard.

## 2. Kiến trúc hệ thống

Ứng dụng được xây dựng theo mô hình frontend tĩnh + backend REST API.

### Frontend
- HTML/CSS/JavaScript
- TailwindCSS
- MapLibre GL JS cho bản đồ
- Chart.js cho dashboard thống kê
- Firebase Authentication dùng cho xác thực người dùng

### Backend
- Node.js + Express
- PostgreSQL (kết nối qua `BE/config/db.js`)
- Xác thực JWT từ Firebase trong middleware
- Lưu trữ tương tác người dùng: lịch sử tìm kiếm, danh sách so sánh, yêu thích

## 3. Luồng chính và tính năng

### 3.1. Tìm kiếm mặt bằng

Trang tìm kiếm cho phép lọc theo:
- Từ khoá
- Thành phố/quận
- Giá thuê
- Diện tích
- Loại hình kinh doanh

Frontend sử dụng `FE/js/pages/main.js` để thu thập bộ lọc, lưu lịch sử và điều hướng tìm kiếm.

### 3.2. Bản đồ và hiển thị kết quả

Trang `FE/js/views/timkiem.html` tích hợp MapLibre để hiển thị các marker mặt bằng trên bản đồ.

### 3.3. So sánh mặt bằng

- Mỗi listing có nút so sánh (compare) trên thẻ.
- Danh sách so sánh được lưu server-side qua API `/api/interactions/compare`.
- Trang so sánh `FE/js/views/sosanh.html` tải danh sách id và hiển thị bảng so sánh theo hình ảnh, tiêu đề, giá, diện tích, khu vực, loại hình và mô tả.
- Giới hạn tối đa 4 mặt bằng trong danh sách so sánh.

### 3.4. Lịch sử tìm kiếm

- Người dùng có thể xem lại 5 tìm kiếm gần nhất.
- Lịch sử được lưu trong PostgreSQL và quản lý qua API `/api/interactions/history`.
- Frontend hiển thị dropdown gợi ý khi người dùng focus vào ô tìm kiếm.

### 3.5. Yêu thích và lưu trữ tương tác

- Frontend có các nút yêu thích trên thẻ listing.
- Dữ liệu tương tác gồm danh sách so sánh, lịch sử tìm kiếm và yêu thích được gửi lên backend để lưu trữ.

### 3.6. Trang chi tiết và hỗ trợ AI

Trang chi tiết `FE/js/pages/chitiet.js`:
- Hiển thị thông tin đầy đủ của mặt bằng.
- Cho phép xem bản đồ và chỉ đường.
- Có logic tích hợp chatbot AI hỗ trợ tư vấn tìm mặt bằng phù hợp.

## 4. Backend chi tiết

### 4.1. Routing và controller

Backend sử dụng Express route tách riêng chức năng:
- `BE/routes/interaction.routes.js` quản lý lịch sử tìm kiếm và so sánh.
- `BE/controllers/interaction.controller.js` chứa logic thêm/xóa và truy vấn dữ liệu.

### 4.2. Xác thực

- Middleware `BE/middlewares/auth.js` dùng Firebase admin để xác thực token.
- Middleware này giúp bảo vệ các route nhạy cảm và đồng bộ người dùng với cơ sở dữ liệu.

### 4.3. Cơ sở dữ liệu

- PostgreSQL lưu thông tin interaction users.
- Bảng `search_history` lưu lịch sử tìm kiếm, giới hạn 5 bản ghi mới nhất.
- Bảng `compare_list` lưu danh sách so sánh.

## 5. Đánh giá và nhận xét

### Ưu điểm
- Kiến trúc rõ ràng, frontend/backendu tách biệt.
- Tính năng tương tác người dùng (so sánh, lịch sử) được triển khai đầy đủ.
- Hỗ trợ người dùng chưa đăng nhập bằng `client_user_id` lưu tại localStorage.
- UI có thanh so sánh nổi và trang so sánh chi tiết.
- Backend kiểm soát được giới hạn số lượng so sánh và xử lý xóa/toggle hợp lý.

### Hạn chế
- Trang so sánh hiện tại fetch toàn bộ dữ liệu qua `fetchAllData(20, "")`, nếu danh sách so sánh chứa item nằm ngoài 20 bản ghi đầu tiên thì có thể không hiển thị chính xác.
- Chưa có API chuyên biệt để lấy chi tiết theo danh sách `property_id`, hiện đang lọc cục bộ từ dữ liệu trả về.
- Các phần thông báo lỗi và feedback người dùng có thể được nâng cấp để rõ ràng hơn.

## 6. Đề xuất cải tiến

- Thêm API backend `GET /api/properties?ids=...` để fetch chính xác các bất động sản trong danh sách so sánh.
- Hiển thị trạng thái nút so sánh rõ ràng hơn khi đã đạt giới hạn 4 item.
- Bổ sung cơ chế đồng bộ người dùng đăng nhập với dữ liệu guest để giữ lịch sử khi login.
- Mở rộng dashboard admin để thống kê lượt xem, hành vi tìm kiếm và so sánh.

## 7. Kết luận

SpaceRent là một sản phẩm hệ thống đầy đủ với các tính năng tìm kiếm, so sánh và tương tác dành cho người thuê mặt bằng. Thiết kế sử dụng công nghệ web phổ biến, giải quyết đúng yêu cầu tìm kiếm và tư vấn mặt bằng, đồng thời có thể mở rộng thêm các API tối ưu và trải nghiệm người dùng.
